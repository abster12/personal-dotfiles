~/.dotfiles workflow reference

What is <leader>? In your config <leader> is the Space key. So <leader>ff means press Space then f f. <C- means Ctrl, <A- means Option, <S- means Shift.

⚓ Harpoon keymaps defined in ~/.config/nvim/lua/plugins/harpoon.lua

KeysWhat it does
<leader>aAdd current file to Harpoon's list
<leader>hShow Harpoon menu — pick a file to jump to
<leader>1Jump to harpoon slot 1
<leader>2Jump to harpoon slot 2
<leader>3Jump to harpoon slot 3
<leader>4Jump to harpoon slot 4

💡 Workflow: Mark the 3–4 files you're actively working on with <leader>a, then bounce between them with <leader>1–<leader>4. Much faster than buffer-switching or finding files again.

📁 Oil keymaps defined in ~/.config/nvim/lua/plugins/oil.lua

KeysWhat it does
-Open parent directory as an Oil buffer (from any file)
<leader>eOpen Oil as a file explorer in current directory
qClose the Oil buffer (custom mapping overrides default)

💡 What makes Oil special? The directory listing is an editable buffer. Use normal vim keys: dd to delete, p to paste, cw to rename, then :w to apply changes. No need for a separate file tree plugin.
